# Snake Game 🐍

A responsive browser-based Snake Game built using HTML, CSS, and JavaScript.

## Features

- Score and high-score tracking
- High score saved using Local Storage
- Game timer
- Wall collision detection
- Snake self-collision detection
- Restart functionality
- Keyboard controls
- Mobile touch controls
- Swipe controls for mobile
- Responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Controls

### Desktop
- ⬆️ Arrow Up — Move Up
- ⬇️ Arrow Down — Move Down
- ⬅️ Arrow Left — Move Left
- ➡️ Arrow Right — Move Right

### Mobile
- Use the on-screen direction buttons
- Swipe on the game board to move

## How to Run

1. Clone the repository:
   `git clone YOUR_REPOSITORY_URL`
2. Open `index.html` in your browser.

## Game Rules

- Eat the red food to increase your score.
- Avoid hitting the walls.
- Avoid hitting your own body.
- Try to beat your high score.
